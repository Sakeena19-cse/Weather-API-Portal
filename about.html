About WeatherSphere

Smart Weather Forecasting and Monitoring Portal

About the Project

WeatherSphere is a web-based weather monitoring portal designed to provide users with real-time weather information and forecast updates for different cities. It uses the OpenWeatherMap API to retrieve weather data and presents the information through a simple and interactive user interface.

Project Objectives

Live Weather

View current weather conditions for different cities.

Weather Forecast

Explore upcoming weather conditions through forecast data.

Air Quality

Check air pollution information and pollutant levels.

Weather Insights

Understand weather patterns using interactive charts.

Technologies Used

HTML5 CSS3 JavaScript OpenWeatherMap API Chart.js

Project Information

Project Type: Web-Based Application
